## Answer Relevance

In a RAG application, LLM is used to generate a concise, direct answer to the user's query using the context retrieved from a knowledge base. The answer thus generated by the LLM should be directly pertinent to the posed user's query, effectively addressing the core inquiry. Answer Relevance score measures the degree to which the user's information need has been met.

## Importance of Answer Relevance

Answer Relevancy is particularly crucial in RAG (Retrieval-Augmented Generation) evaluation because it directly measures how well the system addresses what users actually asked for, which is often the primary failure point in RAG applications.

Here's why Answer Relevancy stands out as especially important:

**The Core Challenge of RAG Systems** - RAG applications can technically retrieve relevant documents and generate fluent text, yet still completely miss the user's intent. Answer Relevancy specifically measures whether the final output actually answers the question posed, making it a critical end-to-end metric.

**Beyond Technical Correctness** - While other metrics like retrieval precision or factual accuracy are important, they don't guarantee user satisfaction. A RAG system might retrieve perfect documents and generate factually correct content, but if that content doesn't address the user's specific question, the system has fundamentally failed from the user's perspective.

**Catches Integration Failures** - Answer Relevancy reveals problems that emerge from the interaction between retrieval and generation components. For example, the retriever might find relevant passages, but the generator might focus on tangential details rather than the core question. This metric addresses integration issues that component-level metrics may overlook.

**User Experience Impact** -  In production RAG applications, irrelevant answers are often worse than admitting uncertainty. Users lose trust quickly when a system confidently provides detailed responses that don't actually help them. Answer Relevancy directly measures this user-facing quality.

**Holistic System Performance** - While retrieval metrics tell you about one component and generation metrics about another, Answer Relevancy evaluates whether the entire RAG pipeline accomplished its fundamental purpose: providing relevant responses to user queries.

## Estimating Answer Relevance Score

The two commonly used approaches to estimate the Answer Relevance score are -
1. Generating Synthetic Questions. - A Reverse Engineering Approach
2. LLM Evaluator

### Generating Synthetic Questions - A Reverse Engineering Approach

The RAG workflow involves a user query that queries the knowledge base to retrieve relevant context. The *relevant context*, along with the *user query*, is used to generate a *response* using LLM. In order to evaluate the *generated response* for its relevance to the *user query*, we adopt a reverse engineering approach. 
With this approach, the questions are synthesized using the *generated response* as context. 
 The *Semantic Similarity* score between the *user query* and the synthesized questions serves as a measure of the Answer Relevancy score. The intuition behind this approach is that, if the context can generate questions that are semantically similar to the *user query*, then the context should be relevant to the *user query* in the first place.

Formally, 

$$
Answer Relevancy Score = 1/N\displaystyle\sum_{i=1}^N sim(q, q(i))
$$

Where
 - q is the user query
 - q<sub>g</sub> is the set of generated questions
 
This approach is adopted in the RAGAS framework.

#### Practical Tips

The prompt for synthesizing questions should impose strict guidelines on the type of questions to be generated, otherwise the generated questions will be highly specific focusing on any factual details within context. The questions should be a very high-level focusing on the whole aspect or theme of the context provided. Failing to impose this restriction will generate questions that semantically diverges from the actual user query. This results in lower Answer Relevancy score. 
Also, it is recommended to restrict the number of questions generated from 3 to 5. Since, we are averaging the similarity scores, even one semantically divergent question can decrease the overall score. This will not give a true estimate of answer relevancy.

##### Example - 1: Generic Prompt


In this prompt, there were no guidelines for generating questions, hence questions generated diverges from the actual user query .This reduces the Answer Relevance score even when the answer is totally relevant.

###### Input - Prompt to synthesize questions using the provided context

```
""" You are a helpful Question generating agent that would generate questions from the provided context.

Context: Common gut microbiota alterations observed in patients with primary sclerosing cholangitis (PSC) include:

- Reduced bacterial diversity compared to healthy controls.
- Increased abundance of the Veillonella genus (which is also associated with other chronic inflammatory and fibrotic conditions).
- Enrichment in genera such as Akkermansia, Ruminococcaceae (undefined genus), and Clostridium.
- Increased numbers of bacteria belonging to the Blautia and Barnesiellaceae genera, and major shifts in Clostridiales order operational taxonomic units.
- Decreased abundance of Prevotella.
"""

```

###### Output - Generated Questions

```
1. What are the common alterations in gut microbiota observed in patients with primary sclerosing cholangitis (PSC) compared to healthy controls?
2. Which bacterial genera are found to be increased in abundance in the gut microbiome of PSC patients?
3. How is the diversity of gut microbiota affected in individuals with primary sclerosing cholangitis?
4. Are Veillonella and Akkermansia more abundant in the gut microbiome of patients with PSC, and what other conditions are associated with Veillonella?
5. In PSC patients, which bacterial genera and families show increased numbers, and which ones are decreased?
6. What are the specific changes observed in the order Clostridiales in the gut microbiota of PSC patients?
7. How does the abundance of Prevotella differ in the gut microbiome of PSC patients compared to healthy controls?
8. In what ways is the gut microbiome profile of PSC patients distinct from that of healthy individuals?
```


##### Example - 2: Specific Prompt

This is a refined version of the prompt to generate more high-level questions considering the whole context and not just a portion of it. Also, we have provided in-context examples. This approach generates questions that are more semantically similar to the  *user query*, hence leading to more reliable Answer Relevancy score.

```
"""You are a helpful Question Generating agent. You will be provided with a CONTEXT.
Generate a set of 3 High-Level questions that would retrieve the CONTEXT from a knowledge base. 

While generating the questions, the following guidelines should be followed:

1. The context should be considered as whole unit. Do not break it down into smaller parts.
2. The question should be like a summary of the context.
3. The question should be specific to the context provided and should be non-trivial.
4. The output format should be a list.
5. Don't focus on any specific details in the context. Instead, focus on the overall theme or topic.

Here is an example:

CONTEXT:
Non-alcoholic fatty liver disease (NAFLD) is strongly associated with sleep apnea syndrome (SAS), particularly obstructive sleep apnea (OSA). 
OSA is considered an independent risk factor for the development and progression of NAFLD, as it contributes to liver damage through mechanisms 
such as oxidative stress, lipid peroxidation, inflammation, and insulin resistance. Sleep disruption and poor sleep quality are also linked with 
increased NAFLD risk and severity, independent of obesity in some patients.In addition, OSA is associated with more severe liver fibrosis and 
advanced liver disease in NAFLD patients. Therefore, the relationship is bidirectional, with sleep apnea contributing to NAFLD progression, and 
NAFLD potentially influencing sleep quality, highlighting sleep disorders as potentially modifiable factors in the management and prevention of NAFLD.

QUESTIONS:
1.What is the relationship between non-alcoholic fatty liver disease and sleep apnea?
2.How does obstructive sleep apnea contribute to the progression of non-alcoholic fatty liver disease?

CONTEXT:
Common gut microbiota alterations observed in patients with primary sclerosing cholangitis (PSC) include:

- Reduced bacterial diversity compared to healthy controls.
- Increased abundance of the Veillonella genus (which is also associated with other chronic inflammatory and fibrotic conditions).
- Enrichment in genera such as Akkermansia, Ruminococcaceae (undefined genus), and Clostridium.
- Increased numbers of bacteria belonging to the Blautia and Barnesiellaceae genera, and major shifts in Clostridiales order operational taxonomic units.
- Decreased abundance of Prevotella.

QUESTIONS:

"""

```

##### Output - Generated Questions

```
1. What are the common alterations in gut microbiota observed in patients with primary sclerosing cholangitis? 
2. How does the gut microbiota composition in primary sclerosing cholangitis patients differ from healthy individuals? 
3. What overall changes in microbial diversity and bacterial genera are associated with primary sclerosing cholangitis?
```


### LLM Evaluator

While the previous approach use LLM to generate questions to estimate Answer Relevancy, there is another dominant approach of using LLM as an Evaluator. This approach is being increasingly used in RAG applications. Here are some examples for estimating  Answer Relevancy using LLM. 
This approach outputs relevance score either as a boolean or discrete labels. The scores are not continuous as in the case of the former approach.

#### Example - 1: Langchain - Boolean output

Prompt used by the *Langchain* framework to compute Answer Relevancy score in terms of boolean output.

```
"""You are a teacher grading a quiz. You will be given a QUESTION and a STUDENT ANSWER. Here is the grade criteria to follow:
(1) Ensure the STUDENT ANSWER is concise and relevant to the QUESTION
(2) Ensure the STUDENT ANSWER helps to answer the QUESTION

Relevance:
A relevance value of True means that the student's answer meets all of the criteria.
A relevance value of False means that the student's answer does not meet all of the criteria.

Explain your reasoning in a step-by-step manner to ensure your reasoning and conclusion are correct. Avoid simply stating the correct answer at the outset."""

```

#### Example - 2:  Discrete scores

A prompt to rate Answer Relevance on a scale of 1-5.

```
"""You are an AI assistant responsible for evaluating the relevance of a RAG system's answer to a user's question [3, 1].

**User Query:**
{query}

**Generated Response:**
{response}

**Evaluation:**
1.  Does the response directly and accurately address the user's query?
2.  Does the response stay on the subject matter of the user's query?

Based on the above, provide a relevance score (1-5, where 5 is highly relevant) and a brief explanation for your assessment.
"""
```

## Summary
These two different approaches to estimate answer relevancy score has its own pros and cons. Combining these approaches will be more helpful to have a reliable estimate of the relevancy.
